# Fuel Coach

Telegram-бот з порадами щодо харчування для тріатлетів. Поради будуються на фактичних тренуваннях і показниках відновлення з **intervals.icu**: туди вже синхронізуються Garmin (активності, HRV, пульс спокою, сон), ваги Garmin Index і Strava.

Мета спортсмена — **стабільна вага**, без набору м'язової маси. Тренування відбуваються зранку.

## Що робить

| Коли | Що надсилає |
|---|---|
| 08:15 | Вага, жир, м'язи, вода, ІМТ, тренд ваги; статус відновлення (HRV, RHR, сон); що з'їсти перед тренуванням |
| Кожні 10 хв (05:00–22:00) | Нове тренування → сніданок-відновлення (БЖВ + 3 рецепти), гідратація, вуглеводи під час таких сесій, план на решту дня |
| Друге тренування < 60 хв після першого | Оновлений сніданок з урахуванням обох (brick) |
| 13:00, якщо тренувань немає | План дня відпочинку |
| 20:00 | Підготовка до ранкового тренування: банан + 50 мл кави + вода (+ розширений варіант) |
| Неділя 20:30 | Тижневий звіт: години, навантаження, вага, HRV, сон, алкоголь і десерти, поради від ШІ |

Ручні записи — звичайний текст боту: «2 келихи вина», «шматок торта», «важко в шлунку після гелю». Claude оцінює калорії, вуглеводи й алкоголь, і вони віднімаються з плану дня.

Кнопки 👍/👎 під рецептами: рецепти, що не сподобались, більше не пропонуються.

## Як рахується

Усі цифри рахуються детермінованими формулами в `src/services/nutrition.ts`. ШІ складає лише рецепти, розбирає ручні записи й пише тижневий висновок.

- **Сніданок-відновлення:** вуглеводи 0.7 / 1.0 / 1.2 г/кг (легке / помірне / важке), білок 0.35–0.4 г/кг, жири 15–20 г.
- **Добові вуглеводи** за сумарним навантаженням (load/TSS): 3 г/кг (відпочинок), 4 (<60), 5 (<120), 6.5 (<200), 8 (≥200).
- **Білок** 1.6 г/кг (1.8 при load ≥ 150, 1.9 при поганому відновленні). **Жири** — решта калорій, мінімум 0.8 г/кг.
- **Калорії:** BMR (Mifflin-St Jeor) × 1.35 + витрати на тренування (для велосипеда кДж ≈ ккал) ± корекція за трендом ваги.
- **Тренд ваги:** експоненційне згладжування й нахил за 14 днів. Корекція — половина тижневого дрейфу, максимум ±300 ккал.
- **Відновлення:** HRV проти 7-денної норми, RHR проти 30-денного середнього, сон < 6/7 год. При поганому відновленні дефіцит калорій вимикається.
- **RED-S:** попередження, якщо вага падає > 0.4 кг/тиждень і відновлення погане 3+ дні.

## Запуск

```bash
cp .env.example .env   # заповнити
npm install
npm run db:migrate
npm run dev
```

Тести: `npm test`.

Деплой на Railway: `railway.json` уже налаштований (міграція + старт). Потрібен Postgres (Supabase або плагін Railway).

## Обмеження MVP

- План тренувань з TrainingPeaks не підтягується: API TrainingPeaks доступний тільки партнерам. Вечірня порада базується на тому, що було в цей день тижня минулого тижня.
- М'язова маса й вода з Garmin Index можуть не передаватися в intervals.icu (залежить від налаштувань синхронізації). Тоді ці поля просто не показуються.
- Один спортсмен (`TELEGRAM_CHAT_ID`). Схема БД уже має `chat_id` для кількох користувачів.
